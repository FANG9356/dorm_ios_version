# คู่มือการรีเซ็ตระบบและเคลียร์การผูก LINE ลูกบ้าน (DormiNetX Reset Runbook)

เอกสารนี้รวบรวมขั้นตอนและคำสั่งสำหรับการรีเซ็ตระบบในสภาพแวดล้อมทดสอบ (Testing Environment) เพื่อให้สามารถทดสอบขั้นตอนการทำงานต่างๆ ซ้ำได้อย่างสะดวก รวดเร็ว และปลอดภัย

---

## ⚠️ กฎสำคัญที่สุด: สถาปัตยกรรม Local-First

DormiNetX ถูกออกแบบด้วยสถาปัตยกรรม **Local-First Architecture**:
- **ข้อมูลหลักจะถูกจัดเก็บอยู่บนเครื่อง iPhone** ด้วยฐานข้อมูล SwiftData (`account_{id}.store`)
- **ข้อมูลบนเซิร์ฟเวอร์ (Cloud Backend)** ทำหน้าที่เป็นจุด Sync Snapshot และเป็นฐานข้อมูลสำหรับ LINE Bot / LIFF
- **ดังนั้น หากต้องการรีเซ็ตระบบเพื่อเริ่มนับ 0 ใหม่จริง จะต้องดำเนินการทั้ง 2 ฝั่งคู่กันเสมอ (Server + iPhone)**
  *(หากล้างเฉพาะเซิร์ฟเวอร์ แต่ไม่ได้ลบแอปบน iPhone เมื่อ iPhone เชื่อมต่ออินเทอร์เน็ต ระบบ Sync จะผลักข้อมูลห้องพักและลูกบ้านเดิมกลับขึ้นไปบนเซิร์ฟเวอร์ทันที)*

---

## 1. คำสั่งลัดและเมนู Interactive บน Terminal Mac

สคริปต์จัดการรีเซ็ตระบบได้รับการติดตั้งไว้บนเซิร์ฟเวอร์เรียบร้อยแล้วที่:  
`/home/fang/dorminet_workspace/reset_test_env.sh`  
*(ทุกคำสั่งมีระบบสำรองฐานข้อมูลอัตโนมัติไปยังโฟลเดอร์ `backups/` บนเซิร์ฟเวอร์ก่อนดำเนินการเสมอ)*

คุณสามารถเปิด Terminal บน Mac แล้วเลือกใช้งานได้ 2 รูปแบบ:

### รูปแบบ A: เปิดเมนูกดเลือกตัวเลข (Interactive Menu)
```bash
ssh -t fang@202.29.232.28 'bash /home/fang/dorminet_workspace/reset_test_env.sh'
```
หน้าจอจะแสดงเมนูดังนี้:
```text
=================================================
      เครื่องมือรีเซ็ตระบบสำหรับทดสอบ DormiNetX      
=================================================
1) ปลดการผูก LINE ลูกบ้านทั้งหมด (Unlink LINE Only)
2) รีเซ็ตข้อมูลหอพักทั้งหมดจาก 0 (เก็บบัญชี Admin เดิมไว้)
3) รีเซ็ตเกลี้ยง 100% แบบโรงงาน (Factory Reset รวม Admin)
4) ดูสถานะและจำนวนข้อมูลปัจจุบัน (Status)
5) ยกเลิก / ออก (Exit)
-------------------------------------------------
กรุณาเลือกตัวเลือก [1-5]:
```

### รูปแบบ B: ยิงคำสั่งตรงแบบ One-Liner (ไม่ต้องผ่านเมนู)
| งานที่ต้องการทำ | คำสั่งใน Terminal Mac |
|---|---|
| **ปลดการผูก LINE ลูกบ้านทั้งหมด** | `ssh -t fang@202.29.232.28 'bash /home/fang/dorminet_workspace/reset_test_env.sh line'` |
| **รีเซ็ตข้อมูลหอพักเริ่มจาก 0 (เก็บ Admin)** | `ssh -t fang@202.29.232.28 'bash /home/fang/dorminet_workspace/reset_test_env.sh data'` |
| **รีเซ็ต 100% แบบโรงงาน (ลบรวม Admin)** | `ssh -t fang@202.29.232.28 'bash /home/fang/dorminet_workspace/reset_test_env.sh factory'` |
| **ตรวจสอบจำนวนข้อมูลปัจจุบัน (Status)** | `ssh fang@202.29.232.28 '/home/fang/dorminet_workspace/reset_test_env.sh status'` |

## 2. ขั้นตอนการทำงานแบบแยกตามกรณี

---

### กรณีที่ 1: เคลียร์เฉพาะการผูก LINE ของลูกบ้าน (Unlink LINE Only)
> **เหมาะสำหรับ:** ต้องการทดสอบขั้นตอนที่ลูกบ้านเข้ามาผูกห้องใหม่ผ่าน LIFF / LINE OA โดยไม่ต้องลบห้องพักหรือข้อมูลหอพัก

1. **รันคำสั่งบน Terminal Mac:**
   ```bash
   ssh -t fang@202.29.232.28 'bash /home/fang/dorminet_workspace/reset_test_env.sh line'
   ```
2. **สิ่งที่ระบบดำเนินการ:**
   - เคลียร์ข้อมูลตาราง `line_links` ใน Master Database
   - ปรับสถานะ `line_user_id` ในฐานข้อมูลลูกบ้านทุกคนให้เป็นค่าว่าง `""` และปรับ `bot_state = 'none'`
   - ล้างคิวการแจ้งเตือนตกค้างใน `line_notification_outbox`
3. **ผลลัพธ์ที่ลูกบ้านจะพบ:**
   - **เมื่อเปิด LIFF:** หน้าจอจะแสดงแบบฟอร์มยืนยันตัวตน ให้กรอก **"เลขห้อง"** และ **"เบอร์โทรศัพท์"** เพื่อผูกบัญชีใหม่
   - **เมื่อพิมพ์คุยกับ LINE OA:** บอทจะตอบว่ายังไม่ได้ผูกห้องพัก และแนะนำให้กดปุ่ม "ผูกบัญชี" จากเมนูด้านล่าง

---

### กรณีที่ 2: รีเซ็ตข้อมูลหอพักใหม่จาก 0 (แนะนำสำหรับการทดสอบทั่วไป 👍)
> **เหมาะสำหรับ:** ต้องการล้างห้องพัก, ลูกบ้าน, บิล, สลิป, และงานแจ้งซ่อมทั้งหมดเพื่อเริ่มนับ 0 ใหม่ **โดยยังคงเก็บบัญชี Admin เดิมไว้** (ไม่ต้องเสียเวลาลงทะเบียน Admin ใหม่)

#### ขั้นตอนที่ 2.1: ล้างข้อมูลฝั่ง Server
เปิด Terminal Mac แล้วรันคำสั่ง:
```bash
ssh -t fang@202.29.232.28 'bash /home/fang/dorminet_workspace/reset_test_env.sh data'
```
ระบบจะหยุดเซอร์วิสชั่วคราว, สำรองข้อมูล, ล้างข้อมูลธุรกรรมทั้งหมดใน Tenant Database และ Master Database, ล้างไฟล์สลิปใน `uploads/`, แล้วเปิดเซอร์วิสใหม่อัตโนมัติ

#### ขั้นตอนที่ 2.2: ล้างข้อมูลฝั่ง iPhone (สำคัญมาก)
1. **บนเครื่อง iPhone 11:**
   - แตะค้างที่ไอคอนแอป **DormiNetX** บนหน้าจอ Home
   - แตะเลือก **"เอาแอปออก" (Remove App)** -> เลือก **"ลบแอป" (Delete App)** -> ยืนยันลบ
   *(การลบแอปจะทำให้ iOS กวาดล้างไฟล์ SwiftData, แคช และประวัติในเครื่องออก 100%)*
2. **ติดตั้งแอปใหม่กลับเข้าไป:**
   - **วิธีที่ A:** เปิด Xcode แล้วกดปุ่ม **Run (Cmd + R)** ติดตั้งลง iPhone 11 ตามปกติ
   - **วิธีที่ B:** รันคำสั่งบิลด์และติดตั้งผ่าน Terminal บน Mac (ดูรายละเอียดในหัวข้อที่ 3 ด้านล่าง)
3. **เข้าใช้งาน:**
   - เปิดแอป DormiNetX
   - เข้าสู่ระบบด้วย **อีเมลและรหัสผ่านเดิมของ Admin**
   - หน้าจอจะว่างเปล่า สะอาด 100% เริ่มสร้างประเภทห้อง, ห้องพัก และลูกบ้านใหม่จาก 0 ได้ทันที

---

### กรณีที่ 3: รีเซ็ตเกลี้ยง 100% แบบโรงงาน (Factory Reset รวมบัญชี Admin)
> **เหมาะสำหรับ:** ต้องการเริ่มระบบใหม่ตั้งแต่ขั้นตอนการ Register สร้างหอพักหน้าแรกสุด

#### ขั้นตอนที่ 3.1: ล้างข้อมูลฝั่ง Server
เปิด Terminal Mac แล้วรันคำสั่ง:
```bash
ssh -t fang@202.29.232.28 'bash /home/fang/dorminet_workspace/reset_test_env.sh factory'
```
*(พิมพ์ `y` เพื่อยืนยันการล้างระบบ)*

#### ขั้นตอนที่ 3.2: ล้างข้อมูลฝั่ง iPhone
1. แตะค้างที่ไอคอนแอป DormiNetX บน iPhone แล้วเลือก **"ลบแอป" (Delete App)**
2. ติดตั้งแอปใหม่กลับเข้าไป
3. เมื่อเปิดแอปจะเข้าสู่หน้า **"ลงทะเบียนผู้ดูแลระบบใหม่"** ทันที

## 3. ขั้นตอนการ Build และติดตั้งแอปใหม่ลง iPhone ผ่าน Terminal (Quick Install)

หากไม่ต้องการเปิด Xcode สามารถสั่งบิลด์และติดตั้งลงเครื่อง iPhone 11 ("F") ผ่าน Terminal Mac ได้โดยตรงด้วยคำสั่งนี้:

```bash
cd /Volumes/FangB/dorm_project/DormAppSwift_Sources/DormiNetX

DORMINETX_DERIVED_DATA="$(mktemp -d /tmp/dorminetx-derived.XXXXXX)"

xcodebuild build \
  -project DormiNetX.xcodeproj \
  -scheme DormiNetX \
  -configuration Debug \
  -destination 'platform=iOS,id=00008030-001C65A134C0A02E' \
  -derivedDataPath "$DORMINETX_DERIVED_DATA" \
  -allowProvisioningUpdates

xcrun devicectl device install app \
  --device 8443F450-FF77-56AB-BE70-0CCCCFDE5C76 \
  "$DORMINETX_DERIVED_DATA/Build/Products/Debug-iphoneos/DormiNetX.app"

xcrun devicectl device process launch \
  --device 8443F450-FF77-56AB-BE70-0CCCCFDE5C76 \
  com.dorminet.DormiNetX
```
