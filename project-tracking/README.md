# Project Tracking

โฟลเดอร์นี้ใช้ติดตามงานที่ยังไม่ปิดและบันทึกผลตรวจระบบรอบปัจจุบัน โดยแยกจากเอกสารประเมินย้อนหลังใน `project-review` และเอกสารสถานะรุ่นใน `docs`

## ไฟล์ในโฟลเดอร์

- [PENDING_WORK.md](PENDING_WORK.md) — backlog งานที่ยังต้องทำก่อน production และงานหลัง pilot
- [UI_LINE_AUDIT_CHECKLIST.md](UI_LINE_AUDIT_CHECKLIST.md) — checklist สำหรับตรวจหน้าจอ iOS, LIFF และ LINE bot พร้อมตารางบันทึกปัญหา

## วิธีอัปเดต

1. เปลี่ยนสถานะรายการเป็น `กำลังทำ`, `รอตรวจ`, `ติดเงื่อนไข` หรือ `เสร็จแล้ว`
2. ปัญหาที่พบระหว่างตรวจ UI/LINE ให้บันทึกในตาราง Issue log พร้อมขั้นตอนทำซ้ำและหลักฐาน
3. เมื่อแก้แล้ว ให้ระบุ commit, รุ่นแอปหรือ backend และผลทดสอบซ้ำ
4. อย่าลบรายการที่เสร็จ ให้ย้ายไปหัวข้อ “ปิดแล้วในรอบนี้” เพื่อเก็บร่องรอย
